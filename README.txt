วิธีติดตั้ง (Render + Supabase PostgreSQL)

ติดตั้งใหม่
1. Supabase > SQL Editor: รันไฟล์ schema_pg.sql
2. Supabase > Connect: คัดลอก Session pooler connection string
3. Render > New Web Service (Runtime: Docker) ชี้ไปที่ repo นี้
4. ตั้ง Environment: DATABASE_URL (หรือ DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASS),
   GEMINI_API_KEY (ไม่บังคับ), SETUP_PASS,
   HOTEL_NAME และ HOTEL_PHONE (ไม่บังคับ แสดงในหน้าลูกค้า)
5. เปิด /setup.php หนึ่งครั้งเพื่อสร้าง admin แล้วลบไฟล์ setup.php และตัวแปร SETUP_PASS
6. เจ้าหน้าที่เข้าสู่ระบบที่ /login.php ด้วยผู้ใช้ admin

อัปเดตจากเวอร์ชันเดิม (ฐานข้อมูลมีอยู่แล้ว) รันตามลำดับที่ Supabase SQL Editor (รันซ้ำได้)
1. migration_bookings.sql
2. migration_guest.sql
3. migration_customers.sql
จากนั้นอัปโหลดไฟล์ทั้งหมดทับ แล้ว Deploy
และตั้ง GEMINI_API_KEY ที่ Render (ไม่ฝัง key ในโค้ดแล้ว)
ถ้าเคยฝัง key ไว้ในโค้ดหรือ repo ให้ยกเลิก key เดิมแล้วสร้างใหม่

หน้าลูกค้า (ไม่ต้องล็อกอินก็จองได้)
- /book.php            ตรวจห้องว่าง ส่งคำขอจอง ติดตามสถานะด้วยรหัสการจอง + เบอร์โทร
- /customer_register.php  สมัครสมาชิก (อีเมล + รหัสผ่าน)
- /customer_login.php     เข้าสู่ระบบลูกค้า (ลองผิด 5 ครั้งล็อก 15 นาที)
- /account.php            การจองของฉัน ยกเลิกคำขอที่ยังรอยืนยัน เปลี่ยนรหัสผ่าน
- สมาชิกที่ล็อกอินจะถูกเติมชื่อ/เบอร์/อีเมลในฟอร์มจองให้ และการจองผูกกับบัญชี
- ยังไม่มีอีเมลยืนยันและระบบลืมรหัสผ่านอัตโนมัติ: ลูกค้าติดต่อโรงแรม แล้วเจ้าหน้าที่กด
  "รีเซ็ตรหัสผ่าน" ที่เมนู ลูกค้า เพื่อได้รหัสชั่วคราว

หน้าเจ้าหน้าที่
- เมนู การจอง: ยืนยัน/ปฏิเสธคำขอจากลูกค้า (มีป้ายเตือนจำนวนที่รอ)
- เมนู ลูกค้า: ดูบัญชีลูกค้า รีเซ็ตรหัสผ่าน ปลดล็อก เปิด/ปิดบัญชี

ข้อความยินยอมในหน้าลูกค้าเป็นข้อความตัวอย่าง ควรให้ผู้เชี่ยวชาญตรวจ และมีนโยบายความเป็นส่วนตัวจริงของโรงแรม
